# SmartOps Knowledge Base

This directory contains knowledge documents for RAG (Retrieval-Augmented Generation).

## Categories

- `mysql/` - MySQL故障排查、性能优化、常见问题
- `linux/` - Linux系统运维、性能分析、故障诊断
- `nginx/` - Nginx配置、错误排查、性能优化
- `network/` - 网络故障、连接问题、协议分析
- `http/` - HTTP错误、API故障、Web服务问题
- `cases/` - 历史故障案例、最佳实践

## Knowledge Format

每个知识文档应包含：
- 故障名称
- 现象描述
- 常见原因
- 排查步骤
- 解决方法
- 预防措施
